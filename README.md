## About This Roadmap

If you're starting your journey into Data Analysis — or you're already on the path and need a structured way to keep going — this roadmap is for you.

It's organized into **10 progressive stages**, from the math foundations all the way to AI-assisted analytics in 2026. Every stage links to **the exact course, video, or practice platform** I'd recommend (no fluff, no affiliate links). Where Arabic-language content is available, it's listed alongside the English version so you can learn in whichever language helps you go faster.

**Who this is for:**
- Students entering the Data Analytics field for the first time
- Career switchers from another domain (engineering, finance, marketing)
- Junior analysts who want a structured path to senior level
- Anyone preparing for a Data Analyst / BI Analyst / Analytics Engineer interview

**What's new in this update:**
- Added a dedicated **AI in Data Analytics** section (essential for 2026)
- Added the **Modern Cloud Data Stack** (Snowflake, dbt, Databricks, BigQuery)
- Added real-world Use Cases across Healthcare, Retail, Banking, HR, and Fintech
- Added an Analytics Engineering layer between BI and ML

## Stage 1 · Mathematics for Data Science

You don't need a math PhD — you need **descriptive statistics, basic probability, and a solid feel for distributions**. That's enough for 90% of analytics work.

### Descriptive Statistics

- **Intro to Statistics** — [Udacity Course](https://www.udacity.com/course/intro-to-statistics--st101)

### Arabic Content for Descriptive Statistics

- **Z&#8203;.Analytics** — [Part 1](https://www.youtube.com/watch?v=PEW8MHwINrY&ab_channel=ZAnalytics) · [Part 2](https://www.youtube.com/watch?v=03fgIhcRGwI&ab_channel=ZAnalytics)
- **Algohary AI** — [Descriptive Statistics Series (Playlist)](https://www.youtube.com/watch?v=8wwPwlueoDs&list=PLtsZ69x5q-X_MJj_iwBwpJaLg_C6JGiWW&ab_channel=ElgoharyAI)

> **Goal of this stage:** Be comfortable reading a histogram, knowing when to use mean vs median, understanding standard deviation, and reading a basic distribution.

## Stage 4 · Pandas & NumPy

These are the two libraries that make Python a serious data tool. Pandas is for tabular data; NumPy is for arrays and math.

### Pandas

- **Kaggle — Pandas Course** — [Kaggle](https://www.kaggle.com/learn/pandas)

### NumPy

- **Kaggle — NumPy Tutorial for Beginners** — [Kaggle Notebook](https://www.kaggle.com/code/legendadnan/numpy-tutorial-for-beginners-data-science/notebook)

> **Goal of this stage:** Be able to load a dataset, filter rows, group by columns, compute aggregates, and merge two DataFrames — fluently.

## Stage 5 · Data Cleaning

Real data is messy. **80% of an analyst's time is data cleaning.** Master this and you'll outperform people who only know fancy ML.

### In Python

- **Alex the Analyst — Data Cleaning** — [YouTube](https://www.youtube.com/watch?v=bDhvCp3_lYw&ab_channel=AlexTheAnalyst)
- **Kaggle — Data Cleaning Course** — [Kaggle](https://www.kaggle.com/learn/data-cleaning)

### In SQL

- **Google Career Certificates — SQL Cleaning** — [YouTube](https://www.youtube.com/watch?v=r7GDQt3lZxs&ab_channel=GoogleCareerCertificates)

> **Goal of this stage:** Take any messy CSV — duplicate rows, mixed date formats, inconsistent categories ('Cairo'/'cairo'/'CAIRO'), missing values — and produce a clean, analysis-ready dataset.

## Stage 7 · Exploratory Data Analysis (EDA)

EDA is where you become a detective. Before any model, before any conclusion — you explore.

- **IBM — Exploratory Data Analysis for Machine Learning** — [Coursera](https://www.coursera.org/learn/ibm-exploratory-data-analysis-for-machine-learning)
- **Marketing Analytics EDA Project (Notebook)** — [Kaggle](https://www.kaggle.com/code/jennifercrockett/marketing-analytics-eda-task-final)

> **Goal of this stage:** Given any new dataset, complete a full EDA notebook in under 2 hours — distributions, missing values, correlations, outliers, key segments.

## Stage 8 · Feature Engineering

The difference between a 70%-accurate model and a 90%-accurate model is usually not the algorithm — it's the features.

- **Kaggle — Feature Engineering Course** — [Kaggle](https://www.kaggle.com/learn/feature-engineering)

> **Goal of this stage:** Take raw columns (dates, text, IDs) and craft features that improve model performance — month, quarter, day-of-week, ratios, rolling averages, target encodings.

## Stage 10 · Keep Learning & Practicing

Data Analytics evolves fast. The analyst who stops learning becomes obsolete in 18 months.

- **Stay current** — Subscribe to a few high-signal newsletters (e.g., *Towards Data Science*, *Data Engineering Weekly*).
- **Webinars & workshops** — Many universities and companies host them for free.
- **Compete on Kaggle** — Even reading other people's notebooks teaches you patterns you'd never see otherwise.
- **Follow practitioners on LinkedIn** — Not gurus. Real practitioners who post their own work.
- **Build in public** — Share your projects, mistakes, and lessons. The audience teaches you back.

## Bonus · The Modern Cloud Data Stack

In 2026, most teams have moved off on-prem warehouses. If you want to be relevant in senior roles, you need at least surface-level fluency in the modern stack.

| Layer | Tools to Know | What It Does |
|---|---|---|
| **Sources** | Salesforce, Stripe, GA4 | Where data is born |
| **Ingestion** | Fivetran, Airbyte, Azure Data Factory | Moving data into the warehouse |
| **Warehouse** | Snowflake, BigQuery, Databricks | Where data lives and is queried |
| **Transformation** | dbt, SQLMesh, Coalesce | Modeling, testing, and trust |
| **BI & ML** | Power BI, Tableau, Looker, Python ML | Decision-making and prediction |

> **Where to start:** Pick **dbt** — it's the most transferable skill. Free fundamentals course at [getdbt.com/learn](https://www.getdbt.com/learn/) (independent recommendation; check link at time of use).

## Bonus · AI in Data Analytics (2026)

This is the section nobody had on their roadmap two years ago — and the one that will most differentiate your career going forward.

### The 4 Layers of Modern Analytics

1. **Traditional BI** — Dashboards, KPIs, historical reporting *(Power BI, Tableau)*
2. **AI-Assisted Analytics** — AI drafts SQL, Python, summaries, dashboard ideas
3. **Analytics Engineering** — Trusted metrics, semantic layer, reusable transformations
4. **Agentic Analytics** — AI systems that use data + knowledge + context + tools together

### Practical AI Skills to Build

- **Prompt engineering for analytics** — Writing prompts that produce useful SQL, EDA, and summaries
- **Validating AI output** — Row counts, sample joins, metric definitions
- **Semantic layers** — dbt metrics, Cube, LookML — so AI doesn't pick the wrong revenue logic
- **Workflow design** — Knowing when to use AI and when to think for yourself
- **Privacy & guardrails** — Never paste sensitive data into public AI tools

### The Rule

> *AI drafts. The analyst validates. AI never owns the final answer.*

> *AI is a force multiplier, not a replacement. The analyst who can't use AI will be replaced by an analyst who can.*

## Suggested 6-Month Schedule

A realistic part-time schedule for a working professional or full-time student.

| Month | Focus | Deliverable |
|---|---|---|
| **1** | Math + Python basics | A Jupyter notebook of statistical exercises |
